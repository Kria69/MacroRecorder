# Macro Recorder Pro

**Бесплатное некоммерческое приложение для автоматизации действий на Windows.**

Macro Recorder Pro — это инструмент для записи и воспроизведения последовательностей нажатий клавиш и движений мыши. Приложение предназначено исключительно для легальных целей: тестирования программного обеспечения, автоматизации рутинных задач, помощи людям с ограниченными возможностями и обучения работе с ПК.

## 🛡️ Безопасность и конфиденциальность данных

Мы серьезно относимся к вашей приватности. Macro Recorder Pro разработан по принципу **Local-First** (все данные остаются только у вас).

### Что мы НЕ делаем:
*   ❌ **Не собираем телеметрию:** Приложение не отправляет никаких данных в интернет.
*   ❌ **Не используем облако:** Ваши макросы и настройки хранятся только на вашем жестком диске.
*   ❌ **Не перехватываем контент:** Мы записываем только факт нажатия клавиш и координаты курсора. Содержимое экрана, буфер обмена, пароли или личные файлы не считываются и не сохраняются.
*   ❌ **Не требуем регистрации:** Для работы не нужен email, аккаунт или лицензионный ключ.

### Где хранятся ваши данные?
Все конфигурации, логи и профили макросов сохраняются в защищенной папке пользователя Windows:
`%APPDATA%\MacroRecorder\`

Вы можете в любой момент удалить эту папку, чтобы полностью очистить все следы работы приложения.

## 📥 Установка и запуск

### Системные требования
*   **ОС:** Windows 10 / 11 (x64 или ARM64).
*   **Права:** Для работы с обычными программами права администратора не требуются. Для автоматизации системных утилит (Диспетчер задач, установщики) может потребоваться запуск от имени Администратора.

### Вариант 1: Готовый исполняемый файл (Рекомендуется)
1.  Скачайте последнюю версию из раздела **Releases**.
2.  Распакуйте архив.
3.  Запустите `MacroRecorder-Windows-x64.exe`.

### Вариант 2: Запуск из исходного кода (Для разработчиков)
Требуется установленный Python 3.10+.

```bash
# 1. Клонируйте репозиторий
git clone <url_репозитория>
cd MacroRecorder

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите приложение
python run.py
```

## 📖 Инструкция по использованию

### 1. Запись макроса
1.  Выберите свободный слот профиля в верхней части окна.
2.  Нажмите кнопку **● Record** (или клавишу `F5`).
3.  Выполните необходимые действия: печатайте текст, двигайте мышью, нажимайте кнопки.
4.  Чтобы остановить запись, нажмите **■ Stop** (или `F6`).

### 2. Воспроизведение
1.  Убедитесь, что целевое окно активно.
2.  Нажмите **▶ Play** (или `F7`).
3.  Приложение автоматически синхронизирует раскладку клавиатуры с той, которая была при записи, и начнет выполнение действий.
4.  Для экстренной остановки нажмите `F8`.

### 3. Управление профилями
*   **Сохранить:** `Alt + S` (сохраняет текущий макрос в файл).
*   **Очистить:** `Alt + C` (удаляет события и сбрасывает имя профиля).
*   **Переименовать:** `Alt + R` (дает профилю понятное название).
*   **Экспорт/Импорт:** Через меню *Profile* можно передать макрос другому пользователю в виде файла `.json`.

### 4. Настройки горячих клавиш
Если стандартные клавиши (`F5`-`F8`) заняты другими программами, зайдите в **Settings → Hotkeys** и назначьте свои комбинации.
*   *Примечание:* Клавиши `Space` и `Win` запрещены в качестве хоткеев во избежание конфликтов с системой.

## 🛠️ Для разработчиков

### Структура проекта
*   `macro_recorder/app.py` — основная логика UI и управления состоянием.
*   `macro_recorder/mouse_input.py` — низкоуровневая эмуляция мыши через WinAPI `SendInput`.
*   `macro_recorder/layout_utils.py` — модуль синхронизации раскладок клавиатуры.
*   `macro_recorder/profiles.py` — работа с хранением и валидацией данных.

### Сборка EXE
Для создания автономного файла используется PyInstaller. Скрипты для GitHub Actions настроены на сборку под архитектуры x64 и ARM64.

```bash
pyinstaller --noconfirm --clean --onefile --windowed --name MacroRecorder run.py
```
